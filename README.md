# Money Tour Android — téléchargement de test

Cette branche conserve l’APK de test signée, les preuves de recette et leurs empreintes SHA-256. Le code source, les règles, les commandes de compilation et les rapports de recette se trouvent sur [la branche main](https://github.com/Virtuel21/Money-tour-android/tree/main).

Télécharger `Money-Tour-Android-0.1.0-debug.apk`, ouvrir le fichier sur Android puis autoriser son installation si le système le demande. Android 7.0+, WebView/Chrome 111+ et WebGL 2 requis.

Version 0.1.0, code 1, application `com.moneytour.android`. Construite depuis le code Android de `6d94b1c` ; inclut le recentrage des champs au-dessus du clavier Android. Le jeu d’origine provient de `Virtuel21/money-tour` au commit `a56b9b1`. Licence MIT ; voir les crédits dans le code source.

SHA-256 : `39d4c86205cdfc172763381607ba9f8786811789355e22aeefadbb8d4d8939f4`.

Aucune clé de signature privée n’est présente dans cette branche. L’APK est une version de test, disponible hors Google Play. Les essais sur téléphone et entre réseaux physiques distincts restent nécessaires ; les rapports distinguent les tests exécutés et leurs limites.

L’archive `Money-Tour-Android-0.1.0-recette.zip` contient les rapports, journaux et captures. Après extraction, ouvrir `index.html` pour parcourir les preuves hors connexion. Le fichier `android-ui-overview.png` donne un aperçu rapide des écrans.
